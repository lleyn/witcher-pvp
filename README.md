# Duel Ledger

Статический PvP-помощник для настольной The Witcher TRPG. Он импортирует файлы
`.witcher.json` из Witcher Sheet, рассчитывает пошаговые атаки и сохраняет
воспроизводимый журнал боя. Все файлы обрабатываются локально в браузере.

## Что уже работает

- одиночный импорт и импорт первого персонажа из массива;
- совместимость со схемой Witcher Sheet 3 и миграция характеристик схем 1–2;
- инициативы и взрывные d10 с фиксированным seed;
- ближние и дальние атаки, уклонение, смена позиции, блок и СЛ 10;
- сильные и прицельные удары, случайные зоны, зональная броня и абляция;
- критический бонус по степени ранения без воспроизведения закрытых таблиц;
- локальные настройки, журнал боя и экспорт JSON/Markdown;
- экспорт обновлённых персонажей для обратного импорта;
- адаптивный интерфейс и доступные элементы управления.

## Разработка

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
npm run build
```

Проект не требует базы данных или серверного API. После сборки каталог `dist/`
можно публиковать на GitHub Pages. Workflow `.github/workflows/pages.yml`
делает это автоматически при push в `main` или `master`.

### Публикация на GitHub Pages

1. Создайте публичный репозиторий и отправьте в него ветку `main` или `master`.
2. В настройках репозитория откройте **Pages** и выберите источник **GitHub Actions**.
3. Дождитесь завершения workflow **Deploy Duel Ledger to GitHub Pages**.

Vite использует относительные пути, поэтому сайт работает как в корне
`username.github.io`, так и по адресу `username.github.io/repository/`.
