# Duel Ledger

Статический PvP-помощник для настольной The Witcher TRPG. Он импортирует файлы
`.witcher.json` из Witcher Sheet, рассчитывает пошаговые атаки и сохраняет
воспроизводимый журнал боя. Можно играть на одном экране или с двух устройств
через комнату по ссылке.

## Что уже работает

- одиночный импорт и импорт первого персонажа из массива;
- совместимость со схемой Witcher Sheet 3 и миграция характеристик схем 1–2;
- инициативы и взрывные d10 с фиксированным seed;
- ближние и дальние атаки, уклонение, смена позиции, блок и СЛ 10;
- сильные и прицельные удары, случайные зоны, зональная броня и абляция;
- критический бонус по степени ранения без воспроизведения закрытых таблиц;
- локальные настройки, журнал боя и экспорт JSON/Markdown;
- экспорт обновлённых персонажей для обратного импорта;
- онлайн-комнаты без аккаунта: владелец управляет бойцом A, приглашённый — B;
- отдельный выбор защиты на устройстве защищающегося игрока;
- авторитетное состояние и броски у владельца комнаты с проверкой очередности;
- адаптивный интерфейс и доступные элементы управления.

## Онлайн-комнаты

GitHub Pages остаётся статическим хостингом. Браузеры находят друг друга через
бесплатный сигналинг PeerJS Cloud, после чего состояние боя передаётся напрямую
по зашифрованному WebRTC DataChannel. Полный исходный лист не пересылается:
соперник получает имя, характеристики, навыки, оружие, броню, текущие ресурсы
и предупреждения импорта. Биография, деньги, заметки и исходный идентификатор
листа остаются на устройстве владельца.

Комната живёт, пока открыта вкладка её владельца. В некоторых корпоративных
сетях и за строгим NAT прямое соединение без отдельного TURN-сервера может не
установиться; в таком случае можно использовать локальный режим.

## Разработка

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
npm run build
```

Проект не требует базы данных, аккаунтов или собственного серверного API. После
сборки каталог `dist/` можно публиковать на GitHub Pages. Workflow
`.github/workflows/pages.yml` делает это автоматически при push в `main` или
`master`.

### Публикация на GitHub Pages

1. Создайте публичный репозиторий и отправьте в него ветку `main` или `master`.
2. В настройках репозитория откройте **Pages** и выберите источник **GitHub Actions**.
3. Дождитесь завершения workflow **Deploy Duel Ledger to GitHub Pages**.

Vite использует относительные пути, поэтому сайт работает как в корне
`username.github.io`, так и по адресу `username.github.io/repository/`.
