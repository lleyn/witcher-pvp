# Duel Ledger

Статический боевой движок для настольной The Witcher TRPG. Он импортирует файлы
`.witcher.json` из Witcher Sheet, моделирует PvP и PvE на условном поле и
сохраняет воспроизводимый журнал боя. Можно играть на одном экране, против ИИ
или с двух устройств через комнату по ссылке.

## Что уже работает

- одиночный импорт и импорт первого персонажа из массива;
- совместимость со схемой Witcher Sheet 3 и миграция характеристик схем 1–2;
- инициативы и взрывные d10 с фиксированным seed;
- ближние и дальние атаки, уклонение, смена позиции, блок и СЛ 10;
- атакующее действие по правилам: две быстрые атаки либо одна сильная;
- одна дополнительная быстрая или сильная атака за 3 Выносливости со штрафом −3;
- прицельные удары, случайные зоны, зональная броня и абляция;
- четыре поля боя с дистанцией, укрытиями, высотой, сложным грунтом и опасными зонами;
- перемещение, бег, три положения тела, захват, толчок, обезоруживание,
  опрокидывание, оглушение, прицеливание и подготовленное действие;
- критические раны четырёх степеней, кровотечение, длительные штрафы,
  стабилизация и лечение;
- состояния: огонь, яд, ослепление, замедление, ослабление, обездвиживание,
  регенерация и магическая защита;
- магия со встречными проверками, Энергией, Выносливостью, Решимостью,
  дальностью, осечками, перезарядкой, поддержанием и длительными эффектами;
- восемь нейтральных магических пресетов для знаков, заклинаний, инвокаций и ритуалов;
- PvE-каталог из десяти оригинальных архетипов монстров четырёх уровней угрозы;
- тактический ИИ монстров, который учитывает дистанцию, ресурсы, состояния,
  предпочтительный стиль, сопротивления и уязвимости;
- локальные настройки, журнал боя и экспорт JSON/Markdown;
- экспорт обновлённых персонажей для обратного импорта;
- онлайн-комнаты без аккаунта: владелец управляет бойцом A, приглашённый — B;
- разные URL комнаты: приватная ссылка владельца восстанавливает роль A после
  обновления страницы, а приглашение всегда открывает роль B;
- отдельный выбор защиты на устройстве защищающегося игрока;
- авторитетное состояние и броски у владельца комнаты с проверкой очередности;
- адаптивный интерфейс и доступные элементы управления.

## Онлайн-комнаты

GitHub Pages остаётся статическим хостингом. Браузеры находят друг друга через
бесплатный сигналинг PeerJS Cloud, после чего состояние боя передаётся напрямую
по зашифрованному WebRTC DataChannel. Полный исходный лист не пересылается:
соперник получает имя, характеристики, навыки, оружие, броню, текущие ресурсы
и предупреждения импорта. Биография, деньги, заметки и исходный идентификатор
листа остаются на устройстве владельца.

Комната живёт, пока открыта вкладка её владельца. В некоторых корпоративных
сетях и за строгим NAT прямое соединение без отдельного TURN-сервера может не
установиться; в таком случае можно использовать локальный режим.

После создания комнаты адрес в строке браузера является приватной ссылкой
владельца. Её не нужно отправлять сопернику: для него предназначена отдельная
кнопка «Копировать приглашение». Обновление страницы сохраняет роль и код
комнаты, но текущий незавершённый бой по-прежнему хранится только в памяти
вкладки и начнётся заново.

## Разработка

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
npm run build
```

Проект не требует базы данных, аккаунтов или собственного серверного API. После
сборки каталог `dist/` можно публиковать на GitHub Pages. Workflow
`.github/workflows/pages.yml` делает это автоматически при push в `main` или
`master`.

### Публикация на GitHub Pages

1. Создайте публичный репозиторий и отправьте в него ветку `main` или `master`.
2. В настройках репозитория откройте **Pages** и выберите источник **GitHub Actions**.
3. Дождитесь завершения workflow **Deploy Duel Ledger to GitHub Pages**.

Vite использует относительные пути, поэтому сайт работает как в корне
`username.github.io`, так и по адресу `username.github.io/repository/`.
